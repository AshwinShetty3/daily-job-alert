PERSONAL JOB SEARCH AUTOMATION

Daily Job Alert

A personal tool operated by Ashwin Shetty that collects DevOps, cloud, infrastructure and related job openings into an email digest.

How it works

The Python application combines supported job APIs and RSS feeds with job-alert emails, filters openings by role, experience, location and posting date, and groups results into India and Outside India / Remote sections. Delivery history helps avoid repeat alerts.

It is designed for a daily GitHub Actions run at 8:00 AM India time; execution may be delayed. Sources, quotas and configuration affect coverage. This website provides information about the tool; it does not offer public account registration.

Why Gmail access is requested

With the account owner's consent, the application reads unread messages under the JobAlerts label, extracts job details and application links, and marks successfully processed alerts as read with a processed label. The Gmail modify permission allows this reading and labeling. It grants broader mailbox capabilities than a label-only permission; the application limits its queries to the configured label.

Digests are sent to the configured recipient using Gmail SMTP and an App Password. OAuth authorization is performed separately on the owner's computer.

Your data

Job-alert content is processed by the configured runner and included in the digest. Credentials belong in private secret storage. Read the privacy policy for access, storage, retention and revocation details, and the terms of service for use conditions.

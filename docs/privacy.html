Privacy policy

Effective date: 4 October 2026

This policy describes Daily Job Alert, a personal automation operated by Ashwin Shetty. Contact: absshetty123@gmail.com.

Data accessed and purpose

After authorization, the application uses the Gmail API to list mailbox labels and read unread messages within the configured JobAlerts label. It processes sender information, message identifiers, receipt dates and message content to extract job titles, companies, locations, experience, dates, descriptions and application links. It uses these details solely to filter, deduplicate and deliver the requested job digest.

The gmail.modify permission supports reading alerts and updating their read status and labels. Successfully processed alerts are marked read and assigned JobAlertsProcessed. The application does not intentionally delete messages. Gmail SMTP uses the configured sender, recipient and App Password to send digests.

Processing and storage

Processing occurs on the owner's computer, a configured self-hosted runner, or GitHub Actions infrastructure. OAuth credentials and tokens are stored locally during setup; operational tokens and the SMTP App Password are stored in GitHub Actions secrets or equivalent private configuration.

An HTML digest preview is written to the execution filesystem. Local previews remain until deleted. Hosted runner files are temporary. Optional preview artifacts, if enabled, may contain alert data and are configured for three-day retention; they should remain disabled for this public repository.

SHA-256 hashes derived from job details and processed message IDs, delivery timestamps and API request-budget records are kept in repository state to prevent repeat delivery. These records remain until removed, and public repository history can retain previous versions. Hashes are not a guarantee of anonymity. Raw message bodies and OAuth tokens are not intended to be committed to the repository.

Sharing and service providers

Google processes mailbox access and email delivery. GitHub processes secrets and data needed to execute hosted workflows. The digest is delivered to the configured recipient and remains in their mailbox until deleted. Job providers receive search parameters and normal network request information; this application does not send Gmail message contents or credentials to job providers.

Google user data is not sold, used for advertising, or used to train generalized AI models. The application does not provide a human-review service. The owner and people they authorize to administer their infrastructure may access data stored there.

Daily Job Alert's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Control, retention and deletion

The account owner can stop scheduled runs, revoke OAuth access through Google Account connections, revoke the App Password, and delete stored secrets, local credentials, tokens, previews and digests. Revocation prevents future authorized access but does not erase already stored copies. Removing historical repository records may require history cleanup. Contact the operator for help with data deletion.

This website and changes

These pages contain no application analytics, tracking scripts, forms or sign-in mechanism. GitHub Pages may process visitor network information under GitHub's privacy statement. Material changes to Google-data use will be disclosed here and require renewed consent where applicable.
